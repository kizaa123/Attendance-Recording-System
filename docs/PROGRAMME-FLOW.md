# Programme-first attendance flow

## Steps

1. **Create a programme** (sidebar **Programmes** → **+**): code, name, department (e.g. BSc Computer Science).
2. **Register students** on that programme (Student Enrollment / enrol link). Each gets one QR for their department.
3. **Take attendance**: choose programme → **Take attendance** → type the **course/module name** for this session (e.g. `CS 101 — Intro to Computing`) → **Start scanning**.
4. Students scan the **same QR** every time; the session is stored under the name you typed.

Many course names can run on the same programme in one day — each name is a separate attendance session.
