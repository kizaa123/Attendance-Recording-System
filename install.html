Install Attendify

Same app on your phone. Data stays on your Render server (one shared database).

Android (Chrome)

  1. Open your Attendify site on Render in Chrome.
  2. Tap Install Attendify below, or Menu → Install app / Add to Home screen.

iPhone (Safari)

  1. Open the site in Safari (not Chrome).
  2. Tap Share → Add to Home Screen → Add.

Native app (Play Store / App Store)

Use the Capacitor project in this repo. See docs/MOBILE-APP.md. The app opens your Render URL; no second database.
